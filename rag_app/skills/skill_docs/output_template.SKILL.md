# output_template

## Purpose
Ensure every answer follows a consistent, decision-friendly format.

## Output sections
1. `Recommendation`
2. `Why` (evidence-backed rationale)
3. `Risk Notes`
4. `Required Checks`
5. `References` (PMID-linked)

## Formatting rules
- Keep recommendation concise.
- Separate evidence from opinion.
- Always include uncertainty language when evidence grade <= C.
