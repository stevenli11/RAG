=============================================================================
                          🎉 NEW FEATURES
=============================================================================

1. OCR Model Support (📸)
   ------------------------
   - Added support for image files: JPG, JPEG, PNG, BMP, TIFF, TIF
   - Automatic OCR for scanned PDF documents
   - Intelligent fallback: direct text → OCR when needed
   - Uses DashScope qwen-vl-max model
   - Smart document type detection

2. Question Classification System (🧠)
   ------------------------------------
   - Automatic question classification into 3 categories:
     * Knowledge - explanations, definitions, general knowledge
     * Experiment - experimental design, protocols, research plans  
     * General - other question types
   - Dynamic prompt selection based on question type
   - Context-aware responses for better answer quality
